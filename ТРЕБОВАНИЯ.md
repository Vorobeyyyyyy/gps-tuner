# GPS Tuner — требования

Android-приложение для настройки USB GPS-приёмника u-blox прямо на ГУ, **без root** и без u-center.

---

## 🎯 Назначение

- Посмотреть текущие настройки приёмника и его живой статус.
- Изменить настройки и сохранить их в память приёмника.

**Главный сценарий:** вернуть 1 Гц после неудачной настройки на 10 Гц, не добираясь до адаптера.

---

## 📱 Окружение

| | |
|---|---|
| ОС | Android 9 (API 28) и новее |
| Целевое устройство | ГУ Belgee S50 / Emgrand SS11 (IHU718P), альбомный экран |
| Приёмник | u-blox M8 — основная цель; u-blox 6/7 — частично (без Galileo) |
| Подключение | Родной USB u-blox (VID `1546`, CDC-ACM); мосты CH340, CP210x, PL2303, FTDI |
| Права | Только доступ к USB-устройству (стандартный запрос Android). Root не нужен. |

**Не поддерживаются в v1:** u-blox M9/M10 (другой механизм настроек, CFG-VALSET), MediaTek, SiRF, Quectel. Приложение должно сообщить «не поддерживается», а не ломать настройки.

---

## ⚠️ Что пользователь делает сам: освобождает адаптер

С USB-устройством в Android может работать **только одно приложение**. Адаптер обычно занят **USB GPS** (UsbGps4Droid). Приложение не останавливает USB GPS само: без root это невозможно.

### Перед подключением
1. Откройте **USB GPS** и остановите сервис (кнопка Stop / выключатель).
   - Или выключите ползунок USB GPS в **FreeTUGA Кнопках**.
2. Убедитесь, что USB GPS не запустился снова. Значок в шторке должен пропасть.
3. Откройте GPS Tuner → «Подключить».

### После настройки
1. В GPS Tuner нажмите «Отключить».
2. Снова запустите USB GPS: кнопка «Открыть USB GPS» в приложении или ползунок в Кнопках.
3. Если координат нет — перезагрузите ГУ.

### Что приложение для этого обеспечивает
- Если адаптер не найден, в пустом списке одна строка: «Подключите GPS к USB с передачей данных и остановите USB GPS — адаптер доступен только одному приложению».
- Если адаптер занят, при подключении появляется ошибка: «Адаптер занят USB GPS — остановите его и подключитесь снова». Рядом кнопка «Открыть USB GPS».
  - Android показывает адаптер в списке, даже когда его держит USB GPS. Конфликт проявляется только при подключении, поэтому основная подсказка здесь.
- Приложение **не регистрируется** на подключение USB-устройства (`USB_DEVICE_ATTACHED`). Так оно не перехватывает автозапуск USB GPS и не сбрасывает галочку «Запускать по умолчанию».
- При выходе и по кнопке «Отключить» порт полностью освобождается. После отключения — короткое напоминание запустить USB GPS снова, с кнопкой «Открыть USB GPS».

## ✅ Функции v1

### 1. Подключение
- Список найденных USB-приёмников: название и VID:PID.
- Запрос разрешения на доступ к USB.
- Для мостов — автоопределение скорости: 9600, 38400, 115200, 57600, 19200, 4800. Признак правильной скорости — валидные NMEA- или UBX-сообщения.
- **Демо-режим без адаптера.** Эмулятор приёмника для проверки интерфейса.

### 2. Информация о приёмнике
Из UBX-MON-VER:
- поколение чипа (M8 и т. д.);
- версия прошивки;
- версия протокола;
- поддерживаемые системы.

### 3. Живой статус (обновление раз в секунду)
- Тип решения: нет / 2D / 3D.
- Спутники: используется / видно.
- Точность в метрах, скорость, точность скорости (UBX-NAV-PVT, опрос без изменения настроек).
- **Реальная частота NMEA**: сколько RMC приходит в секунду. Это то, что получает USB GPS.
- **Загрузка порта** (только адаптеры с мостом): байты NMEA в секунду относительно скорости UART. Это то, что получит USB GPS.
  - Собственные UBX-опросы приложения не считаются.
  - NAV-SAT (сотни байт) на мосту опрашивается раз в 3 с, чтобы не забивать порт.
- Уровни сигнала по спутникам с разбивкой по системам (UBX-NAV-SAT).

### 4. Настройки (читаются из приёмника)

| Параметр | Значения | Сообщение |
|---|---|---|
| Частота | 1 / 2 / 5 / 10 Гц | CFG-RATE |
| Модель движения | Автомобиль, Портативная, Пешеход, Стационарная, Море, Воздух | CFG-NAV5 (только dynModel) |
| Системы | GPS, ГЛОНАСС, Galileo, BeiDou, QZSS, SBAS | CFG-GNSS |
| NMEA-сообщения | GGA, GLL, GSA, GSV, RMC, VTG | CFG-MSG (текущий порт) |
| Скорость порта (только адаптеры с мостом) | 9600, 38400, 57600, 115200 | CFG-PRT (UART1) |

У родного USB u-blox скорости порта нет (CDC-ACM её игнорирует), поэтому строка «Порт» показывается только для мостов CH340/CP210x/PL2303/FTDI.

**Смена скорости порта** идёт последней командой:
1. CFG-PRT уходит на старой скорости.
2. Через 150 мс ГУ переключается на новую. ACK приходит уже на новой.
3. Если ACK потерялся — связь проверяется опросом. Если не отвечает — скорость ГУ возвращается обратно.

Ограничения M8 соблюдаются в интерфейсе:
- ГЛОНАСС и BeiDou одновременно не включаются;
- не больше 3 основных систем;
- GPS выключить нельзя.

### 5. Пресеты

| | Частота | Системы | Зачем |
|---|---|---|---|
| **Навигатор** | 1 Гц | GPS + ГЛОНАСС + Galileo + SBAS + QZSS | Больше спутников. С Galileo предел M8 во flash — 3 Гц |
| **Быстрый** | 5 Гц | GPS + ГЛОНАСС + SBAS + QZSS | Быстрее реакция на развязках. 5 Гц — ровно предел M8 во flash для двух систем |

Общее у обоих: модель «Автомобиль», **NMEA только RMC и GGA**, скорость порта не трогается.
- SBAS и QZSS — дополнения к GPS. Предел 5 Гц u-blox даёт вместе с ними.
- «Быстрый» на мосту с 9600 бод: около 750 байт/с, то есть ~78% порта. Влезает; строка «Порт» покажет загрузку.

Кнопки на панели внизу: «Навигатор · 1 Гц» и «Быстрый · 5 Гц». На узком экране они собраны в меню «Пресет».

Плитка «Частота NMEA» зелёная, пока частота в пределах возможностей приёмника, и красная, если выше.

**Почему только RMC и GGA.** Проверено по исходникам UsbGps4Droid (`NmeaParser.java`):
- координаты строятся только из **RMC** (скорость, курс) и **GGA** (координаты, высота, число спутников, HDOP);
- точка уходит в Android, только когда пришли оба сообщения одной эпохи;
- «точность» для навигатора = HDOP × 10 м;
- GSA, VTG, GLL USB GPS разбирает и выбрасывает, GSV не читает вовсе. А GSV — самое тяжёлое: несколько строк на каждую систему в каждую эпоху.

Без лишних сообщений данных в 5–7 раз меньше: при 1 Гц RMC + GGA занимают около 15% от 9600 бод. Поэтому на адаптере с мостом скорость поднимать не нужно, и в USB GPS ничего менять не придётся.

### 6. Применить и сохранить
- **«Применить»** — изменения уходят в оперативную память приёмника. Отправляются только изменённые параметры, на каждую команду ждём ACK.
- **«Сохранить в приёмник»** — UBX-CFG-CFG во flash/BBR. Потом настройки перечитываются для проверки.
- Пока есть несохранённые изменения, виден индикатор «Не сохранено». После выключения машины такие изменения пропадут.

### 7. Сброс к заводским
Только с подтверждением. Текст подтверждения: сбросятся все настройки приёмника, в том числе те, которых нет в приложении; сохранённое во flash будет стёрто.

### 8. Предупреждения
- **Частота выше предела M8** для включённых систем — точность упадёт, скорость будет скакать. Пределы по данным u-blox:

  | Прошивка | 1 система | 2 системы | с Galileo (3 системы) |
  |---|---|---|---|
  | Во flash («EXT CORE», NEO-M8N) | 10 Гц | 5 Гц | 3 Гц |
  | В ROM («ROM CORE», M8M/M8Q) | 18 Гц | 10 Гц | 10 Гц |

  Тип прошивки берётся из MON-VER. Если его не понять — считаем как flash, это строже.
- **Порт загружен больше чем на 70 / 90%** (мосты) — данные теряются.
- **Скорость порта отличается от той, что была при подключении** — «выставьте её и в USB GPS». То же в напоминании после отключения.
- **Выключены RMC или GGA** — «USB GPS перестанет получать координаты».
- **Смена систем** — «приёмник перезапустится, фикс пропадёт на 30–60 с».

### 9. Перегруженный порт при подключении (мосты)
На 9600 бод со всеми NMEA данные трёх систем не помещаются даже при 1 Гц. Приёмник выбрасывает сообщения, включая ответы на запросы. Чтение настроек тогда тянется минутами, и часть настроек не читается.

Поэтому, если при подключении загрузка порта выше 90%, вместо настроек показывается карточка «Порт перегружен»:
- **«Разгрузить порт»** (основная) — 1 Гц и только RMC + GGA, затем прочитать настройки. Скорость порта не меняется, USB GPS трогать не надо.
  - Команды CFG-RATE и CFG-MSG не зависят от текущих настроек, поэтому их можно отправить до чтения.
  - ACK может потеряться, поэтому до 3 попыток.
- **«Поднять до 115200»** — сменить скорость, затем прочитать настройки. Ту же скорость нужно выставить в USB GPS.
- **«Прочитать как есть»** — читать на текущей скорости, медленно и с пропусками.

### 10. Сброс к заводским — что именно сбрасывается
UBX-CFG-CFG: clearMask = 0xFFFF, loadMask = 0xFFFF, deviceMask = BBR + Flash + EEPROM + SPI Flash.
- **Стираются все разделы конфигурации во всех видах памяти**, в том числе те, которых нет в приложении: порты и протоколы, сообщения, навигация, SBAS, энергосбережение, антенна, логирование и т. д.
- Затем загружаются **умолчания прошивки u-blox**: 1 Гц, Portable, GPS + ГЛОНАСС + QZSS + SBAS, все NMEA, UART 9600.
  - Это не настройки продавца адаптера: если он что-то менял и сохранял, это тоже пропадёт.
- **Не трогается:** прошивка и навигационные данные в BBR (альманах, эфемериды, последняя позиция). Это не настройки, на них держится быстрый старт.
- У адаптера с мостом ГУ после сброса переключается на 9600. Если до этого скорость была другой — появится напоминание выставить 9600 в USB GPS.

## 🎨 Интерфейс
- Альбомная ориентация, тёмная тема, русский язык.
- Компактно: экран должен помещаться **без прокрутки** и при 1920×720 / 240 dpi (≈ 1280×480 dp). На самом ГУ 160 dpi (1920×720 dp), там места с запасом.
- Кнопки и варианты высотой 44 dp.

**Экран «Подключение»** — без прокрутки:
- шапка;
- сообщение, если есть (ошибка или напоминание);
- карточка со списком адаптеров или пустым состоянием и «Демо-режимом».

**Экран «Приёмник»:**
- сверху — устройство, статус, индикатор «Не сохранено»;
- слева — настройки: одна карточка, по строке на параметр (подпись слева, варианты справа);
  - **несохранённые в приёмник изменения показываются самими кнопками, без текста:**
    - пунктирная рамка — состояние кнопки изменится по «Применить»;
    - заливка — каким значение станет; у уходящего значения пунктир бледный;
    - у подписи строки с изменениями — точка цвета акцента;
    - на кнопке «Применить» — счётчик изменений;
  - постоянных подсказок нет, только предупреждения;
  - «Море» и «Воздух» показываются, только если уже выбраны;
- справа — 4 плитки живого статуса в ряд и график сигналов;
- снизу — «Пресет», «Сброс», «Сохранить», «Применить».
- На узком экране панели идут одна под другой.

## 🧪 Приёмка

**Автотесты (JVM, 23 шт.):**
- сценарии кнопок через сессию:
  - пресет «Навигатор» → Применить → Сохранить → Сброс;
  - пресет «Быстрый» → 5 Гц, GPS + ГЛОНАСС, реально ~5 RMC/с;
  - перегруженный мост → «Разгрузить порт» → 1 Гц, RMC + GGA, загрузка < 30%, скорость не менялась;
- UBX-кадры совпадают с проверенными: 1 Гц `…01 39`, Automotive `…53 70`, сохранение `…31 BF`, сброс `…2F AE`;
- разбор смешанного потока NMEA + UBX: склейка и обрывы кадров, мусор между ними;
- кодирование и декодирование CFG-RATE, CFG-NAV5, CFG-GNSS, CFG-MSG, MON-VER, NAV-PVT, NAV-SAT.

**Эмулятор Android 9, демо-режим:**
- все экраны работают без падений;
- «Применить» и «Сохранить» меняют состояние эмулятора приёмника.

**На ГУ (проверяет пользователь):**
1. При запущенном USB GPS «Подключить» показывает «Адаптер занят». После остановки USB GPS приложение подключается, частота RMC ≈ 10/с.
2. Пресет «Навигатор» → Применить → частота 1/с → Сохранить.
3. Выключить и включить машину → в приложении 1 Гц.
4. USB GPS запущен → в Яндекс Навигаторе координаты есть, скорость не скачет.
